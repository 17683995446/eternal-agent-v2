# 永动知识图谱Agent - 示例项目

本目录包含三个示例项目，帮助您快速了解和使用永动知识图谱Agent。

## 示例列表

### 示例1: 基础知识图谱管理 (`example_01_knowledge_base.py`)

展示如何使用永动知识图谱Agent进行：
- 创建和管理知识图谱
- 添加节点和关系
- 查询和检索知识
- 可视化知识图谱

**运行:**
```bash
python example_01_knowledge_base.py
```

### 示例2: 智能问答系统 (`example_02_qa_system.py`)

展示如何构建一个简单的智能问答系统：
- 基于知识图谱的问答
- 推理引擎的使用
- 模式匹配和规则应用
- 自然语言查询解析

**运行:**
```bash
python example_02_qa_system.py
```

### 示例3: 任务自动化工作流 (`example_03_task_automation.py`)

展示如何使用永动循环和任务队列实现自动化工作流：
- 创建和管理任务队列
- 定义任务处理器
- 使用永动循环持续处理任务
- 任务优先级和重试机制

**运行:**
```bash
python example_03_task_automation.py
```

## 快速开始

1. 确保您已经克隆或下载了项目
2. 进入示例目录：`cd examples`
3. 运行任意示例：`python example_01_knowledge_base.py`

## 自定义示例

您可以根据自己的需求修改示例代码：
- 修改节点和关系的定义
- 添加自定义任务处理器
- 扩展问答系统的能力
